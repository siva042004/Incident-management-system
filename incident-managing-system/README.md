# Incident Management System Frontend

React frontend for the Incident Management System. It provides the dashboard, incident list, search, create, edit, and delete screens for the Spring Boot API.

## Stack

- React
- React Router
- Material UI
- Axios

## Run Locally

```bash
npm install
npm start
```

The app starts at `http://localhost:3000`.

Make sure the backend is running at `http://localhost:8080` before using the incident screens.

## Scripts

```bash
npm start
npm run build
npm test
```
